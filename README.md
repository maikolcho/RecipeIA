# RecipeIA 🍳📱

Aplicación iOS desarrollada en **SwiftUI** utilizando **Xcode**, orientada a la búsqueda inteligente de recetas a partir de los ingredientes disponibles por el usuario.

La aplicación emplea una **API con inteligencia artificial** para analizar los ingredientes introducidos y generar recetas personalizadas, ayudando a aprovechar al máximo los alimentos disponibles en la nevera.

## 🧠 Funcionalidades principales
- 🥕 Búsqueda de recetas según ingredientes disponibles
- 🤖 Generación de recetas mediante API con inteligencia artificial
- 🗂️ Filtrado de recetas por categorías
- ⭐ Guardado de recetas favoritas
- ✍️ Creación de recetas personalizadas por el usuario
- 📱 Interfaz moderna y fluida desarrollada íntegramente con SwiftUI

## 🛠️ Tecnologías utilizadas
- Swift
- SwiftUI
- Xcode
- Arquitectura MVVM
- Consumo de APIs REST
- Manejo de estados y vistas reactivas

## 🧩 Arquitectura
El proyecto está estructurado siguiendo el patrón **MVVM**, separando la lógica de negocio de la interfaz de usuario para mejorar la escalabilidad, mantenimiento y legibilidad del código.

## 🎯 Objetivo del proyecto
Proyecto personal desarrollado con fines formativos y de portfolio, enfocado en la integración de APIs externas, el uso de SwiftUI y la aplicación de conceptos modernos de desarrollo iOS.

## 📌 Estado del proyecto
Proyecto personal en desarrollo activo.
